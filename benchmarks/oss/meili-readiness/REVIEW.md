Reviewed the draft at `1bedb7e` against public main at `d519834`. The evidence supports publication of a contributing code path on the studied workload. The neutral term for the remaining gap is a residual regression. [SPE PR #10](https://github.com/SsjRaz/systems-performance-engine/pull/10) · [Original report](../MEILI-PROFILE.md)

**Reproducibility.** The archive checksum and file manifest verified. All six saved decisions and rankings replayed from 96 distinct process windows, 36,864 successful measured requests, 96 external verification requests and 7,404 samples. Fresh symbolization against all four original profiled ELFs reproduced all 16 captures. The protocol binds the corpus, request body, header file, measured executable SHA-256 and build ID. Rebuilding a release can yield a different ELF. Re-symbolization requires the original ELF corresponding to each capture.

**Profiling.** The release and source timing experiments preceded their own four independent diagnostic pairs. The v2 reader reconciles native successes, the extra application receipt, CPU tick granularity and the two-CPU wall-time bound. The exporter adjusts sampled addresses for ELF mappings and preserves the weight of unmapped or non-application frames in the sample denominator. Self-time uses the estimated share of process user CPU per successful search. An ownership intervention supports a causal contribution on the measured workload. The relative rank of an LMDB leaf cannot establish the cause of the remaining regression.

**Patch semantics.** The experimental v1.42.0 patch changes ownership conversion of `IndexFilterCondition::In`. Membership tokens with a borrowed context matching the field's source pointer **and length** share an immutable `Arc<str>`. Each token retains its fragment and optional modified value. Foreign-source and pre-owned tokens preserve their prior ownership path. The field still owns its own context. Both owned representations report the same unavailable column as the previous implementation. The patch includes a mixed-source, modified-token test that drops the original strings before inspecting the result. [Rust patch and test](../meili-share-filter-context.patch)

**Compatibility.** `CowSpan` is a public enum in the unpublished workspace crate `filter-parser`. Adding a variant can break exhaustive matches in a downstream source checkout. The tagged workspace uses such matches only inside the parser. Maintainers may prefer to hide the shared storage within a private representation. The patch also creates a shared context for very short lists. Allocation counts for these cases are part of the follow-up study. SPE's six existing v1 CPU reports also replayed unchanged, covering 61,440 successful requests. Both hosted Linux jobs passed on the reviewed PR head.
